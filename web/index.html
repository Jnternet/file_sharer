把文件或文件夹拖到这里登记

登记时只读取名称/大小并本地算出 SHA-256，不会发送任何文件内容； 等有人点「下载」时才读取并逐块发送。

手机浏览器不支持"选择整个文件夹"，请用「登记文件」多选文件； 需要在手机上分享整个文件夹时，请改用桌面端。

提示：如果「登记文件夹」弹出的是"选择文件"对话框（Linux 上常见），或者选完没有任何反应 （Firefox 对含中文/非 ASCII 名称的文件夹有已知问题），请把文件夹直接拖进这个区域—— 拖放会保留完整目录结构。Chrome/Edge 在 https 或 localhost 下也会走浏览器自带的目录选择。

当前是 http 明文访问：Chrome/Edge 只有在 https 或 localhost 下才能使用 浏览器推荐的系统目录选择器。用 file_sharer --tls 启动后改用 https 地址访问即可 （自签名证书，首次访问选择"继续"）；也可以先用「登记文件」多选，或把文件夹压缩成 zip 再按单文件登记。
