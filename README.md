# file_sharer — 局域网文件直传

一个文件、一个网址，局域网内任意设备互相直传文件与文件夹。

- **单产物**：`cargo build --release` 得到唯一可执行文件，前端资源已编译进二进制。
- **网页访问**：启动后打印 `http://<局域网IP>:<端口>/`，任何能访问该地址的设备打开即用。
- **每次启动都是空桶**：服务器不落盘、不缓存文件字节，只转发信令；进程退出后什么都不留。
- **真·实时直传**：浏览器之间用 WebRTC DataChannel 点对点传输，文件**不会预先上传到服务器**。
- **断点续传**：中断/刷新后重新选择同一批文件即可从断点继续。
- **自动校验**：传输前对源文件算 SHA-256，接收方落盘后复算比对，失败自动要求重传。
- **单文件 / 文件夹自动识别**：拖入什么就传什么，无需手动切换模式。

## 快速开始

```bash
cargo run --release
# 或用构建产物
cargo build --release && ./target/release/file_sharer
```

输出示例：

```
file_sharer 0.1.0 已启动（服务器零存储，每次启动都是空桶）
  本机:   http://127.0.0.1:8080/
  局域网: http://192.168.1.23:8080/
```

在发送端设备打开页面 → 拖入文件/文件夹（或点"选择文件"/"选择文件夹"）→ 在接收端设备打开同一页面 → 选择目标设备 → 接收方看到进度，校验通过后一键下载。

常用参数：

```bash
file_sharer --port 9000            # 指定端口（0 = 随机空闲端口）
file_sharer --bind 127.0.0.1       # 只监听本机（默认 0.0.0.0）
file_sharer --max-peers 20         # 在线人数上限（默认 64）
file_sharer --ice-server stun:stun.l.google.com:19302   # mDNS 被屏蔽时的兜底
```

## 安全边界

这是**局域网内网**工具：任何能访问该端口的人都能收发文件，且传输在浏览器之间明文进行（HTTP + WebRTC）。
不要把它暴露到公网或不可信网络。服务器端零存储是结构性保证（见 `tests/architecture.rs`）。
